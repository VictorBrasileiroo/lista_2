# Como iniciar esta atividade em 10 passos

1. Extraia o ZIP.
2. Não acrescente o PDF original ao repositório público.
3. Execute `python scripts/verificar_estrutura.py`.
4. Leia `docs/00-visao-geral.md` e `docs/02-cronograma.md`.
5. Recupere os dados das 30 instâncias da Lista 1 (Q2).
6. Prepare Python, Java/Protégé e Ollama **apenas conforme a necessidade**.
7. Se quiser, publique esta pasta como repositório público usando os comandos em `README.md`.
8. Abra o Codex nessa pasta e cole `prompts/00-inicial-codex.md`.
9. Traga aqui o link + SHA do commit e logs de execução para validação independente.
10. Depois de aprovado, use os prompts de lotes como modelos para ciclos menores.

**O que este pacote é:** planejamento e scaffold de diretórios/documentos.  
**O que ele não é:** resolução das 15 questões, testes de execução, GitHub remoto criado ou entrega pronta.
