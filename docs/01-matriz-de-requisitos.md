## Não confundir proposta com requisito

- O PDF **não exige Python universalmente**, nem fixa um único relatório final para todas as questões.
- Q7: vídeo **ou demonstração**; Q8/Q9: **apresentação ou vídeo**. Planejar artefatos reais, não confundir roteiro em Markdown com apresentação concluída.
- Q11: o texto apresenta um cenário que *permite* implementar as abordagens, mas a tarefa explicitamente pede uma comparação. Podemos acrescentar pequeno baseline sem transformar isso em aplicação extra obrigatória.
- Q12: inferência + explicabilidade são exigidas, mas não uma biblioteca/framework ou deployment específico.
- Q15: pode reaproveitar o arquivo OWL da Q9, mas precisa demonstrar e discutir efetivamente inferências.
- Q10: há colisão textual no enunciado: "Busca em Profundidade (BFS)". Implementar e rotular corretamente DFS e BFS, declarando a ambiguidade.
- Qualquer indicação de funcionamento clínico real das Q7/Q8 seria indevida: exemplos são para fins educacionais.
